# URBAN ASSAULT × ローグライクハーフ

現代市街戦をテーマにした、1～2人向けの短時間戦術ゲームです。  
FT書房『ローグライクハーフ』の制作に関する利用規約に基づいて制作する非公式バリアントルールです。

  <img src="images/RLH_icon.png" width="180" alt="ローグライクハーフ ロゴ">
</p>

## 作品情報

- プレイヤー人数：1～2人
- プレイ時間：15～30分（シナリオにより変動）
- 対象年齢：12歳以上
- GM：不要
- ジャンル：ミリタリー／現代戦／戦術
- レベル：初級
- 難易度：Normal
- 形式：サプリメント（バリアントルール）
- 世界：オリジナル（現実世界をベースにしたパラレルワールド）

## コアルール

- 現在の開発版：v1.01
- 開発正本：`core/core-rule-full.md`
- `main` は開発正本として使用しますが、公開リポジトリのため常に一般公開可能な内容だけを格納します。
- `public-release` は確認済みの公開安定版です。

## ローグライクハーフ基本ルール

本作を利用する際は、原作である『ローグライクハーフ』基本ルールも参照してください。

## 制作・公開方針

URBAN ASSAULT の本文・シナリオ・データは、独自文章・独自データを原則とします。  
公式作品の本文や、再配布を許可されていない第三者著作物はリポジトリに格納しません。

公開時は、ローグライクハーフの最新の制作に関する利用規約を確認します。
