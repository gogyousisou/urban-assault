## 3. ユーザー判断が必要な事項

### 3-1. Black Sun Protocol の推奨レベル

現在、3つの表記が一致していません。

- ファイル名：`lvl10-16`
- YAML：`recommended_level: 10-16`
- 本文：`経験点12以上`、`適正レベル：12-16`

**推奨：12～16 に統一。**

理由：本文側で 12 以上という指定が2箇所一致しており、トレーニングシナリオより高い敵レベル・長い連戦・3周構造を持つためです。  
採用時は YAML とファイル名も `12-16` へ修正します。

### 3-2. IRストロボライト／航空支援の撃破数

同一シナリオ内で効果が矛盾しています。

- 03章の概要：敵戦闘集団から `1d6体` 撃破
- 10章の専用ルール：敵戦闘集団から `1d3+1名` 撃破

**推奨：`1d3+1` に統一。**

理由：10章は航空支援の専用ルールとして後段で具体化されており、2～4体という範囲は 1～6体より効果の振れ幅が小さく、シナリオの資源管理を壊しにくいためです。

### 3-3. Black Sun Protocol 出目46「車両IED」の攻撃参加上限

現行記述：

> 次に発生する戦闘では分隊員の攻撃参加上限を -2 する（最低1）。

Core v1.01 では通常時の固定「攻撃参加上限」がなく、各戦闘員が原則1回行動するため、何から -2 するかが定義できません。

**推奨：次の戦闘中、各ラウンドに攻撃へ参加できる分隊員数の上限を「その戦闘開始時の生存戦闘員数 -2（最低1）」とする。分隊長はこの上限に含めない。**

出目46で被弾ロールにより選ばれた隊員の「第1ラウンド不参加」は別途そのまま適用します。  
これにより「分断による2名分の火力低下」という元の意図を維持できます。

### 3-4. 既存シナリオの高脅威目標を v1.01 撤退ルールへ移行する方針

Core v1.01 では高脅威目標は自動撤退しません。  
既存シナリオには、生命点と攻撃回数を持つ単体敵があり、旧ルール下では撤退処理が曖昧でした。

港湾制圧訓練では、少なくとも以下を高脅威目標として明示するのが自然です。

- 出目22：専任伍長
- 出目23：軽装甲制圧車両
- 最終イベント：軽装甲偵察車

Black Sun Protocol の 61～66 は既に高脅威目標カテゴリです。

**推奨：v1.01 の新しい基本方針をそのまま採用する。**

- 高脅威目標は自動撤退しない。
- シナリオに明記された固有撤退条件だけを適用する。
- 【死ぬまで戦う】は従来どおり撤退しない。
- Black Sun Protocol 出目62・64の明示済み撤退条件は維持する。

旧ルールの「生命点半分で自動撤退」を互換目的で復活させません。  
難易度への影響は、次のテストプレイ／資源収支監査で確認します。

## 5. 公開安全性の別監査

Black Sun Protocol は実在の軍事作戦・装備・部隊を強く想起させるモチーフを含みます。  
歴史上の事実や一般的な軍事用語そのものとは別に、特定の書籍・映画等の独自表現を転記していないか、公開前に文章表現を独立して監査します。

この監査はゲームルール互換性とは分けて実施し、現段階ではシナリオの物語設定を変更しません。
