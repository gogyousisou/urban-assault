## 11. Black Sun — 2人プレイ時の分隊長戦死処理

ユーザー判断により、Black Sunを2人でプレイしている場合、どちらか一方の分隊長が戦死した時点でその作戦は失敗として終了する。

- 片方の分隊長だけが戦死した場合でも即座に作戦失敗。
- 戦死した側だけ、Core v1.01「41. ゲームオーバーと部隊再編」に従って後任分隊長を作成する。
- 生存している分隊長は交代せず、そのまま次の作戦へ参加する。
- 同じ部隊の継続として、成功数、現在の周、通常d66マップ解決済み履歴を維持する。
- 部隊再編段階は分隊長戦死としてCore v1.01どおり上昇する。
- 次の作戦は同じ周のプロローグから再開する。
- 1～3周目の最終イベント成功条件は、2人プレイでは「いずれの分隊長も戦死していない」ことを含む。

これにより、戦死した分隊長側の戦闘中指揮を誰が引き継ぐかという追加ルールを設けず、1人プレイ時の「分隊長戦死＝作戦失敗」と同じ構造を維持する。

## 12. 2人プレイ時の経験点 — 個別管理

Core v1.01の既存設計に合わせ、2人プレイ時の経験点は各分隊長が個別に管理することを明文化した。

- 作戦完了による経験点は、特記がない限り各分隊長が個別に獲得する。
- Black Sunでは作戦成功時、生存している各分隊長がそれぞれ経験点1点を獲得する。
- Black Sunの成功数は分隊共有の進行値であり、作戦成功1回につき1だけ増える。

これはシナリオ共有資源と分隊長個人の成長資源を区別する既存方針の明文化である。

## 13. Tactical Drill 01 / 02 — 後任分隊長と再編救済を維持

ユーザー判断により、TD1/TD2では「後任分隊長を作成できない」という制限を設けない。

理由：
- Core v1.01「41. ゲームオーバーと部隊再編」の再編段階は、初心者が失敗を重ねても次の挑戦で救済を受けられるための仕組みである。
- TD1/TD2はチュートリアル性が強いため、この救済処置を無効化しない。

確定した扱い：
- 作戦失敗・分隊長戦死後の再挑戦を認める。
- 分隊長が戦死した場合はCore v1.01「41. ゲームオーバーと部隊再編」に従って後任分隊長を作成できる。
- 部隊再編段階は同一シナリオ内で維持する。
- 「1キャラクター1回想定」は、成功済みの同じ分隊長による経験点目的の周回を想定しないという意味に整理する。
- 経験点を獲得できるのは、各分隊長につき本シナリオを最初に成功した1回のみとする。

これにより、チュートリアルとしての初心者救済と、反復による経験点稼ぎの抑制を両立する。

## 16. Core v1.01 — 複数敵単位・混成戦処理の明確化

FIRST FIREの事前監査で、複数の【敵戦闘集団】または【高脅威目標】が同時に参加する戦闘について、敵側行動と撤退処理がCore本文だけでは一意でないことを確認した。

ユーザー承認により、以下を採用する。

- 各【敵戦闘集団】および各【高脅威目標】を、それぞれ独立した「敵単位」として扱う。
- 敵側の手番開始時、複数の敵単位が行動可能な場合はプレイヤーが処理順を決める。
- 1つの敵単位について、攻撃回数決定 → 分隊長／分隊員への攻撃配分 → 防御ロール → ダメージ処理まで完了してから次の敵単位へ進む。
- シナリオに敵単位の処理順が明記されている場合は、その記載を優先する。
- 【撤退】条件を満たした敵単位だけを即座に戦闘から離脱させる。
- 他に戦闘可能な敵単位が残っていなければ戦闘終了。残っていれば戦闘を継続する。
- 【死ぬまで戦う】は対象となる敵単位ごとに適用する。

既存シナリオへの影響確認:

- Tactical Drill 01:
  高脅威目標は通常イベント／最終イベントで単独登場しており、挙動変更なし。
- Tactical Drill 02:
  地上／屋上／前方／後方は同一の敵戦闘集団内の位置区分であり、今回定義する独立した敵単位には分割しない。既存のシナリオ固有撤退条件を維持するため挙動変更なし。
- Black Sun Protocol 出目64〈路地裏の指揮官〉:
  現場指揮官と同行民兵は別敵単位として扱えるが、「同行民兵が半数以下になった場合は指揮官と一緒に撤退」等のシナリオ固有条件がCoreより優先するため、既存挙動を維持する。
- Black Sun Protocol 1周目中間:
  バリケードは攻撃回数0の高脅威目標、民兵は敵戦闘集団として独立処理できる。既存のバリケード防護を維持し、数値変更なし。
- Black Sun Protocol 3周目最終:
  対戦車砲装甲車両の攻撃を民兵と合算せず独立処理する既存規定は、今回のCore一般則と一致する。シナリオ固有の【着弾対象ロール】は引き続き優先する。

この変更は新しい敵能力や難易度補正を追加するものではなく、既存の複数対象戦闘を一意に処理するためのCore v1.01明確化である。


## 17. Core v1.01 — 2人プレイ時の敵攻撃配分案

FIRST FIRE事前監査で、Core 36章の「分隊長側／分隊員側」への攻撃配分が、2人プレイでは分隊長2名・分隊2組に対して一意でないことを確認した。

Draft案として以下を採用している。

- 敵単位ごとに、まずCore 36章どおり分隊長側／分隊員側へ攻撃回数を分ける。
- 分隊長側の攻撃は2人の分隊長へ可能な限り均等に配分する。
- 分隊員側の攻撃は2つの分隊へ可能な限り均等に配分する。
- 奇数で1回余る場合はプレイヤーが対象を決める。
- 各分隊員側攻撃の防御には、その分隊を指揮する分隊長の技量点と適用可能な効果を使用する。
- 被弾ロールもその分隊内だけで解決する。
- 各分隊で分隊員数を超過した攻撃は、その分隊の分隊長へ移る。
- シナリオ固有の対象指定・配分規定がある場合はそちらを優先する。

既存シナリオへの影響:
- TD1 / TD2 / Black Sunはいずれも2人プレイ可だが、既存の敵数・攻撃回数・支給資源を変更する必要はない。
- 「どちらか一方の分隊長が戦死した時点で作戦失敗」という既存方針とも両立する。
- シナリオ固有の着弾対象指定や攻撃対象指定は引き続きCore一般則より優先する。

この変更は2人プレイ時の対象配分を一意にする明確化であり、1人プレイの挙動は変更しない。
