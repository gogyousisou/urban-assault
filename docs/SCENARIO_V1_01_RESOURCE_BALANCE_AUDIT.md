## 1. この監査の位置づけ

これは実プレイ結果ではなく、Core v1.01 の現行ルールと既存テストキャラクターを使った机上監査です。

目的は、v1.01 で明確化した「攻撃ロール1回につき原則弾倉1個」という処理によって、既存シナリオの初期弾倉が明らかに不足または過剰になっていないかを確認することです。

この段階では初期弾倉数を変更しません。

## 2. 基準キャラクター

現行の `testplay/test_chara_kurutu_kiyou.md` のレベル10キャラクターを、Tactical Drill 01・02 の基準例として使用します。

主な攻撃能力：

- 分隊長：DMR使用時 `1d6+2`
- マークスマン：`1d6+1`
- アサルト2名：各 `1d6+1`

Tactical Drill 01・02 は「1ラウンド最大4名まで攻撃可能」のため、上記4名を主な攻撃参加者とした場合を基準にします。

LMG／ガンナーは P0 で承認された基本則に合わせ、射撃回数2をすべて行う場合の弾倉消費は合計2個と明確化済みです。

## 3. 命中率とクリティカル連鎖を含む弾倉効率

分隊長1名（+2）と隊員3名（+1）の4攻撃を平均した、1回の有料攻撃あたりの基礎成功率は次のとおりです。

- 敵レベル3：約83.3%
- 敵レベル4：約70.8%
- 敵レベル5：約54.2%
- 敵レベル6：約37.5%

クリティカル率は1/6で、クリティカル追加攻撃は弾倉を消費せず、さらにクリティカルすれば連鎖します。

そのため、1回の有料攻撃から発生する攻撃ロール総数の期待値は `1.2回` です。

上記4名を同じ比率で使用し、命中修正がない場合の「弾倉1個あたり期待ダメージ」は概ね次のとおりです。

- 敵レベル3：約1.00ダメージ／弾倉
- 敵レベル4：約0.85ダメージ／弾倉
- 敵レベル5：約0.65ダメージ／弾倉
- 敵レベル6：約0.45ダメージ／弾倉

逆に、1ダメージを与えるために必要な有料攻撃の期待値は概ね次のとおりです。

- 敵レベル3：約1.00個
- 敵レベル4：約1.18個
- 敵レベル5：約1.54個
- 敵レベル6：約2.22個

これは平均値であり、実際にはクリティカル連鎖により大きく上下します。また、敵の撤退、攻撃修正、負傷、隊員脱落、射撃技能、特殊装備、オーバーキル等は別途影響します。

## 4. Tactical Drill 01 — 港湾制圧訓練

現行初期弾倉：

- EASY：20
- NORMAL：17
- HARD：15

固定戦闘を、上記4名の通常射撃だけで処理する基準値は次のとおりです。

- 中間イベント：レベル5の敵5体 → 約7.7個
- 最終イベント：レベル5・生命点6の高脅威目標 → 約9.2個
- 固定戦闘合計：約16.9個
- 中間イベントの戦利品弾倉2個を差し引いた実質：約14.9個

したがって NORMAL 17個では、固定戦闘だけなら平均約2.1個の余裕があります。

最終イベントでAT4を使用し2ダメージを与えた場合、通常射撃で必要な残り4ダメージは約6.2個となり、固定戦闘の実質消費は約11.8個まで低下します。

ランダムイベントには追加の敵戦闘と補給の両方が存在します。また、器用型分隊長は【察知】で不利なマップへの進入を回避できるため、実際の資源収支はプレイ方針によって大きく変化します。

### 一次結論

**現時点では 20 / 17 / 15 を維持します。**

NORMAL 17は余裕の大きい設定ではありませんが、補給、察知、AT4等を活用する意味が残る値です。

ただし、コンバットエンジニアの対車両IED能力は使用タイミングと行動消費が未定義のため、上記計算には含めていません。

現時点で増量する根拠はありません。

## 6. Black Sun Protocol

現行初期弾倉：

- EASY：36
- NORMAL：28
- HARD：20

推奨キャラクターレベルは10～16です。

本シナリオは以下の理由から、Tactical Drill より弾倉消費の振れ幅が大きくなります。

- d66ランダムイベントに複数の敵戦闘集団・高脅威目標が存在する。
- 中間イベントと最終イベントが周回ごとに変化する。
- 2周目・3周目は敵数または継続戦闘の圧力が高い。
- 高脅威目標はv1.01では原則として自動撤退しない。
- 一方で、反応結果による戦闘回避、戦利品、航空支援、支給装備などの弾倉節約手段も存在する。

特に3周目は、中間イベントと最終イベントの敵レベルが5で、車両目標も登場するため、NORMAL 28個の安全余裕を重点確認する必要があります。

一方、本シナリオは同一分隊で最大3回プレイする構造で、成功すれば経験点を獲得します。そのため最低レベル帯の代表テストは「10 → 11 → 12」の3周進行として確認する方が実態に近いと判断します。

### 一次結論

**36 / 28 / 20 をいったん維持し、NORMAL 28を重点確認値とします。**

数値変更は、3周進行を含むテスト結果を見てから判断します。

## 8. クリティカル連鎖 — 採用済み

ユーザー判断により、**クリティカルによる追加攻撃は連鎖します。**

- 通常の【攻撃ロール】でクリティカル → 無料の追加【攻撃ロール】を1回行う。
- その追加攻撃でもクリティカルが発生した場合 → さらに無料の追加【攻撃ロール】を1回行う。
- 以後、クリティカルが発生しなくなるまで同じ処理を繰り返す。
- クリティカルによる追加攻撃では弾倉を追加消費しない。

この仕様は、低確率の幸運が連続するダイスゲームらしさを重視したものです。

1回の有料攻撃から発生する攻撃ロール総数の期待値は、クリティカル率を1/6とすると `1 / (1 - 1/6) = 1.2回` です。

資源収支テストでは、この連鎖を有効にした状態で判定します。

## 9. テストを止めている次のルール判断

コンバットエンジニアには次の能力があります。

> IED(即席爆弾)により、1作戦につき1回、車両1体に1ダメージを与える（防御ロール不可）。

しかし現行本文では、以下が未定義です。

- 戦闘前・第0ラウンド・通常ラウンドのどこで使用するか
- コンバットエンジニア自身の行動を消費するか
- 弾倉等の追加資源を消費するか
- 「車両」であれば装甲属性の有無を問わないか

Tactical Drill 01 最終イベントや Black Sun Protocol の車両戦で弾倉収支と被害量に直接影響するため、ここから先の数値テストでは先に仕様を固定する必要があります。

### 推奨案

**コンバットエンジニアのIEDは、戦闘中に自身の1回の行動を消費して使用する。**

- 1作戦につき1回。
- 対象は「車両」または「装甲」属性を持つ高脅威目標1体。
- 第0ラウンドでは使用できない。
- コンバットエンジニア自身のそのラウンドの攻撃の代わりに使用する。
- 判定不要。
- 弾倉消費なし。
- 1ダメージを与え、防御ロールは行わない。

AT4より威力は低い一方、無料隊員が1作戦1回だけ確実な対車両ダメージを出せる特色を残し、行動を消費させることで無料ダメージの過剰な強さを抑える案です。

この仕様を確定後、資源収支・難易度テストを続行します。
