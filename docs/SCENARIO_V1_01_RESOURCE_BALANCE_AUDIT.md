## 1. この監査の位置づけ

これは実プレイ結果ではなく、Core v1.01 の現行ルールと既存テストキャラクターを使った机上監査です。

目的は、v1.01 で明確化した「攻撃ロール1回につき原則弾倉1個」という処理によって、既存シナリオの初期弾倉が明らかに不足または過剰になっていないかを確認することです。

この段階では初期弾倉数を変更しません。

## 2. 基準キャラクター

`testplay/testchara_01.md` のレベル10キャラクターを、Tactical Drill 01・02 の基準例として使用します。

主な攻撃能力：

- 分隊長：DMR使用時 `1d6+2`
- マークスマン：`1d6+1`
- アサルト2名：各 `1d6+1`

Tactical Drill 01・02 は「1ラウンド最大4名まで攻撃可能」のため、上記4名を主な攻撃参加者とした場合を基準にします。

## 3. 命中率の目安

分隊長1名（+2）と隊員3名（+1）の4攻撃を平均した、1回の攻撃ロールあたりの基礎成功率は次のとおりです。

- 敵レベル3：約83.3%
- 敵レベル4：約70.8%
- 敵レベル5：約54.2%
- 敵レベル6：約37.5%

この値は、クリティカルによる無料の追加攻撃を弾倉効率に算入していない保守的な値です。

したがって、実際の平均弾倉効率はこれより良くなります。

## 4. Tactical Drill 01 — 港湾制圧訓練

現行初期弾倉：

- EASY：20
- NORMAL：17
- HARD：15

固定戦闘だけを保守的に見ると、次の弾倉消費が想定されます。

- 中間イベント：レベル5の敵5体 → 約9.2回の攻撃ロール相当
- 最終イベント：レベル5・生命点6の高脅威目標 → 約11.1回の攻撃ロール相当

固定戦闘だけなら約20.3回ですが、中間イベントで弾倉2個を回収でき、クリティカル追加攻撃は無料です。

また、ランダムイベントには弾倉・AT4等を得られる選択肢が複数あり、AT4は装甲目標への消費弾倉を大きく圧縮できます。

一方、ランダムイベントには敵戦闘集団・高脅威目標も含まれるため、NORMAL 17個は余裕の大きい設定ではありません。

### 一次結論

**現時点では 20 / 17 / 15 を維持します。**

理由：

- 資源回収を行う価値を残せる。
- AT4取得が最終戦の弾倉収支に意味を持つ。
- クリティカル無料追加攻撃を含めると机上の消費量は下がる。
- 数値を増やす前に、v1.01での実プレイ確認を行う方が安全。

ただし NORMAL 17 は「余裕あり」ではなく、**資源探索を活用して突破する設計**として扱います。

## 5. Tactical Drill 02 — 区域接触任務

現行初期弾倉：

- EASY：20
- NORMAL：17
- HARD：15

本シナリオは戦闘そのものより、接触兆候を集めて戦闘条件を改善する比重が高い構造です。

中間イベントは2ラウンド経過または敵2名行動不能で敵が撤退します。
最終イベントも3ラウンド経過または敵3名行動不能で撤退します。

したがって、全敵を撃破することを要求する Tactical Drill 01 より、固定戦闘で必要になる弾倉は少なく抑えられます。

情報獲得のために弾倉を支払う選択肢がありますが、その支出が接触兆候を通じて最終戦の難易度を下げるため、資源交換として機能しています。

### 一次結論

**20 / 17 / 15 を維持します。**

現時点で増量する根拠はありません。

## 6. Black Sun Protocol

現行初期弾倉：

- EASY：36
- NORMAL：28
- HARD：20

推奨キャラクターレベルは12～16です。

本シナリオは以下の理由から、Tactical Drill より弾倉消費の振れ幅が大きくなります。

- d66ランダムイベントに複数の敵戦闘集団・高脅威目標が存在する。
- 中間イベントと最終イベントが周回ごとに変化する。
- 2周目・3周目は敵数または継続戦闘の圧力が高い。
- 高脅威目標はv1.01では原則として自動撤退しない。
- 一方で、反応結果による戦闘回避、戦利品、航空支援、支給装備などの弾倉節約手段も存在する。

特に3周目は、中間イベントと最終イベントだけでも高い火力要求があり、NORMAL 28個の安全余裕が小さい可能性があります。

ただし、レベル12～16の代表ビルドがまだ固定されておらず、d66の戦闘回避・補給・航空支援を含めた実際の収支を机上だけで断定するのは危険です。

### 一次結論

**36 / 28 / 20 をいったん維持し、Normal 28を重点確認値とします。**

数値変更は、3周分のテスト結果を見てから判断します。

## 8. テスト開始前に残るルール解釈

Core v1.01 の08章では、攻撃ロールでクリティカルした場合に無料の追加攻撃を行えるとしています。

ただし、**その追加攻撃でも再びクリティカルが出た場合、さらに追加攻撃が発生するか**は明示していません。

資源収支テストを再現可能にするため、この点を先に固定する必要があります。

### 推奨案

**クリティカルによる追加攻撃は連鎖しない。**

- 通常の攻撃ロールでクリティカル → 無料の追加攻撃を1回行う。
- その無料追加攻撃で6が出ても、さらに追加攻撃は発生しない。
- 1回の通常攻撃から発生する無料追加攻撃は最大1回。

理由：

- 1回の弾倉消費から得られる攻撃回数に上限ができ、資源収支を安定させられる。
- 処理が簡単で、ソロプレイでも解釈が分かれにくい。
- クリティカルの爽快感は残しつつ、極端な連鎖を防げる。

この点を確定後、同一条件で資源収支テストを実施します。
