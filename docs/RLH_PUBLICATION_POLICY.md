# URBAN ASSAULT — ローグライクハーフ公開運用ポリシー

URBAN ASSAULT を公開する際の、ローグライクハーフ（RHL）利用規則への対応方針を定めます。

## 1. 参照する公式情報

公開前には必ず、その時点で最新の公式利用規則を確認します。

- RHL 制作に関する利用規則：<https://ftbooks.xyz/ftnews/gamebook/RogueLikeHalf_TOS.pdf>
- RHL 公式基本ルール：<https://ftbooks.booth.pm/items/4671946>

利用規則は改訂される可能性があるため、過去に確認済みであっても公開時に再確認します。

## 2. URBAN ASSAULT の基本方針

- RHL 公式作品はゲームデザイン研究の参考資料として扱います。
- URBAN ASSAULT のルール本文、シナリオ本文、イベント、敵、罠、戦利品等は独自文章・独自データを原則とします。
- 公式作品や第三者作品の本文を、参考資料として GitHub に保存しません。
- 他の RHL 作品の d66 データは、規約上利用可能な場合でも原則として直接流用しません。
- 例外的に第三者データを利用する場合は、利用規則を確認したうえで、必要な出典情報を記録します。

## 3. RHL ロゴ

インターネット上で公開する作品には、RHL 作品であることを示す公式 RLH ロゴを見やすい位置に表示します。

このリポジトリで使用するロゴの正本は次の1点とします。

- `images/RLH_icon.png`

FT書房の公式出版作品を示す別種のマークは使用しません。

## 4. 公開作品に記載する情報

RHL 利用規則で求められる作品情報を、ロゴ画像またはテキストで明示します。

URBAN ASSAULT コアルールの標準表記は次のとおりです。

- プレイヤー人数：1～2人
- プレイ時間：15～30分（シナリオにより変動）
- 対象年齢：12歳以上
- GM：不要
- ジャンル：ミリタリー／現代戦／戦術
- レベル：初級
- 難易度：Normal
- 形式：サプリメント（バリアントルール）
- 世界：オリジナル（現実世界をベースにしたパラレルワールド）

個別シナリオでは、プレイ時間・レベル・難易度など、そのシナリオ固有の値を明示します。

また、RHL 公式基本ルールの配布先 URL を作品内に記載します。

## 5. GitHub 運用

`main` は開発正本ですが、本リポジトリ自体が公開されているため、常に一般公開可能な内容だけを格納します。

`public-release` は公開安定版とし、確認済みの成果物だけを反映します。

公開フロー：

`main → 内容・規約確認 → public-release`

## 6. 公開前チェック

公開前に最低限、次を確認します。

- 最新の RHL 利用規則を再確認したか
- RLH ロゴが見やすい位置にあるか
- 必須の作品情報が記載されているか
- RHL 公式基本ルール URL が記載されているか
- 再配布を許可されていない本文・画像・データが含まれていないか
- FT書房公式出版物を示すマークを誤用していないか
- 第三者データを使用した場合、必要な出典情報が揃っているか
- `main` の内容がすべて一般公開可能か

---

この文書は URBAN ASSAULT 内部の公開運用方針です。公式利用規則と内容が異なる場合は、公開時点の公式利用規則を優先します。
