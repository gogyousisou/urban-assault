## 位置づけ
v1.01配布以降に承認・反映されたCoreルール改定をv1.02として正式な版番号へ整理。戦闘システムの全面刷新ではないが、ゲーム処理・数値の変更を含むためv1.01のまま配布しない。今回のv1.02への版番号変更自体は本文ルールを変更しない。

## 主な差分
- 射撃技能：ラピッドファイアは弾倉1個で一連の2回射撃が可能。見切りの射撃点二重消費を防止
- C4：第0R設置不可。設置と起爆判定のタイミングを明確化し、敵集団最大5体／高脅威目標3ダメージに改定
- 隊員：スカウト／スポッターの察知成功能力、メディックの戦場治療、所持上限関連を改定
- 報酬権限：戦闘勝利・敵撤退だけで自動報酬を発生させず、シナリオまたはマップで決定。鹵獲した固定兵装からの自動弾倉獲得を廃止
- 進行：d33等への対応、既出マップ結果の標準処理、敵種別の◇／◆、反応表の端数範囲処理などを追記・明確化
- 敵単位・攻撃対象・二人用処理・各種例外の記述を明確化
- 作者表記を「ぜっとん」に統一
