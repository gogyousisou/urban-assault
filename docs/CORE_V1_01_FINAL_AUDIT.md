## 2. P8-001 — 複数の敵対象がいる戦闘での【撤退】

現行Core 38には「撤退が発生した場合、戦闘は即座に終了」とある。
一方Core 36では、複数対象の一部だけを捕虜化・鹵獲しても、他の敵が残れば戦闘を継続する。

複数の敵戦闘集団や、高脅威目標＋敵戦闘集団が同時に存在する場合、「1集団の撤退だけで戦闘全体が終了するか」が未確定。

### A（推奨）
撤退した対象だけを戦闘から除外する。
他に戦闘対象となる敵が残っていれば戦闘継続。
敵がすべて撤退・全滅・捕虜化・鹵獲等でいなくなった時点で戦闘終了。
シナリオが「この撤退で戦闘終了」と明記する場合はシナリオ優先。

効果：
- Core 36の複数対象処理と一貫する。
- 混成戦闘で一部の雑兵を撤退させるだけで高脅威目標まで消えることを防ぐ。
- Core 34 / 38 / 47の要約同期が必要。

### B
現行文どおり、いずれかの敵集団が撤退した時点で戦闘全体終了。
残る敵も同時に離脱したものとして扱う。

効果：
- 処理は単純。
- 混成戦闘では、弱い敵集団を半数以下にすることが戦闘全体の早期終了手段になる。

## 3. P8-002 — Black Sun 1周目中間イベント：バリケードと非通常攻撃

現行は「バリケード生命点0まで、民兵を通常の攻撃対象にはできない」とだけ規定している。
そのため、航空支援、フラググレネード、C4等の「通常攻撃ではない効果」がバリケード越しの民兵へ通るかが未確定。

### A（推奨）
バリケード生命点0までは、民兵を攻撃・ダメージ・即時撃破効果の対象にできない。
ただし、【精密射撃】／マークスマン、および「遮蔽物の影にいる敵にも効果を及ぼす」など明示的に防護を無視できる効果は例外。
航空支援・フラググレネード・C4・AT4等、明示的な防護無視を持たない効果では民兵を直接排除できない。
非ダメージ効果は個別記載に従う。

効果：
- バリケードを先に突破する戦術的意味を維持。
- Core【グレネード】の遮蔽物無視など、明記された能力は活用可能。

### B
「通常の攻撃」だけを禁止し、航空支援・消耗装備・その他の特殊効果は民兵へ使用可能。

効果：
- 現行文の字義に近い。
- 航空支援1回でバリケードを無視して民兵の大半を除去できる可能性があり、中間イベントの構造が大きく変わる。

## 4. P8-003 — 2人プレイ時の敵攻撃回数の配分

Core 36は分隊長1人＋分隊員を前提に敵攻撃を半分ずつ配分する。
Core 45は2人プレイを定義しているが、2人の分隊長／2つの分隊へ敵攻撃をどう配るか未定義。

### A（推奨）
敵の総攻撃回数は増やさず、まず2つの分隊へ可能な限り均等に分ける。
奇数で1回余る場合、どちらの分隊が受けるかプレイヤーが選ぶ。
その後、各分隊へ割り当てられた攻撃をCore 36どおり「分隊長／分隊員」へ配分する。

効果：
- 1人プレイと敵の総火力が変わらない。
- 2つの分隊の存在を維持できる。
- 既存の「奇数1回はプレイヤーが配分先を決める」という設計思想とも近い。

### B
2人分を1つの大きな分隊として扱い、Core 36の半数を「分隊長側」、半数を「全分隊員側」へ配分する。
分隊長側の攻撃をどちらの分隊長が受けるかはプレイヤーが選ぶ。

効果：
- 処理は比較的簡単。
- 防御の高い分隊長へ攻撃を集中させやすい。

### C
敵の各攻撃ごとに、どちらの分隊を狙うかランダム決定する。

効果：
- 公平性は高い。
- ロール回数が増え、偏りも発生する。

## 5. P8-004 — 2人プレイ時の【退却】

Core 42は分隊長1人を前提にしており、2人プレイで一方だけが退却できるか未定義。

### A（推奨）
【退却】は作戦側全体の行動として扱う。
どちらかの分隊長が自分の手番開始時に宣言すると、両分隊が同時に退却する。
1戦闘につき1回の制限も作戦全体で共有する。
退却時の敵攻撃はP8-003で決めた2人プレイ時の攻撃配分に従う。

効果：
- 一本道／マップ位置を2分しない。
- 現行シナリオ構造をそのまま使用できる。

### B
各分隊が個別に退却できる。

効果：
- 戦術の自由度は高い。
- 2つの分隊が別マップに存在する状態、再合流、イベント進行、支給資源など追加ルールが必要になる。

## 6. P8-005 — 2人プレイで「分隊長1人」を対象とするイベント

Black Sunには「分隊長がダメージ」「必ず分隊長を攻撃対象」等の記述があり、2人プレイ時にどちらを対象にするか未定義。
非戦闘イベントの能力判定も、どちらの分隊長が担当するか共通則がない。

### A（推奨）
- 非戦闘イベントで分隊長1人が判定・行動する場合：判定前にプレイヤーが担当分隊長を1人選ぶ。結果・ダメージ等はその担当者へ適用。
- 戦闘中に「分隊長1人」を対象とする効果で選択方法がない場合：効果解決前にプレイヤーが対象分隊長を1人選ぶ。
- シナリオに対象指定方法がある場合はそちらを優先。

効果：
- Core 45の「協力や役割分担」を活かせる。
- 追加ダイスが不要。
- 防御の高い分隊長へ危険を集める戦術が可能。

### B
対象分隊長は1d6でランダム決定（1-3＝分隊長A、4-6＝分隊長B）。
非戦闘判定の担当者はプレイヤーが選ぶ。

効果：
- 戦闘時の危険を一方へ意図的に集中できない。
- 追加ロールが必要。

### C
イベント・戦闘ともランダムで担当／対象を決める。

効果：
- 公平だが、2人プレイの役割分担が弱くなる。
