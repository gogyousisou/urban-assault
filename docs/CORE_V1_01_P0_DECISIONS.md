# URBAN ASSAULT v1.01 — P0整合性判断事項

対象：`core/core-rule-full.md`
作業ブランチ：`refactor/v1.01-core-cleanup`

この文書は、コアルールv1.01の整合修正にあたり、既存ルールから一意に決められないP0事項を整理するための判断記録です。
承認前はコアルール本文へ反映しません。

## 1. 1ラウンドの行動単位

現行ルールでは隊員は戦闘に参加して攻撃を行い、武器・隊員には「射撃回数」が設定されています。一方で、1ラウンドに誰が何回行動できるかを共通ルールとして明示していません。

既存チュートリアルシナリオには「1ラウンドに最大4名まで攻撃可能」というシナリオ固有制限があります。このため、コア側では全戦闘員が行動でき、個別シナリオで参加人数を制限できる構造と読むのが最も自然です。

### 推奨案

- 分隊長と、戦闘に参加している各戦闘員は、原則として各ラウンドに1回ずつ行動できる。
- 攻撃を選択した場合、装備または隊員データの「射撃回数」だけ攻撃ロールを行える。
- シナリオに「攻撃人数制限」等がある場合は、そのシナリオ記載を優先する。
- 非戦闘員は通常の攻撃行動を行わない。

## 2. 弾倉消費の単位

現行29章には「射撃攻撃を行うたびに弾倉を1個消費」とあります。LMGは射撃回数2回かつ「弾倉を追加で1消費」とされ、AMRは1回の射撃に弾倉3個を消費します。

この構造から、通常射撃の基本単位は「攻撃ロール1回につき弾倉1個」と読むのが整合的です。

### 推奨案

- 通常の射撃攻撃は、攻撃ロール1回につき弾倉1個を消費する。
- 射撃回数2の武器・隊員が2回とも射撃する場合、原則2個消費する。
- 武器・技能に個別の消費量が明記されている場合は、その記載を優先する。
- クリティカルによる追加攻撃は、現行8章どおり弾倉を追加消費しない。

## 3. 射撃技能と弾倉の関係

現行18〜19章では射撃技能の使用コストとして射撃点1点を定めていますが、【ショットガン】【グレネード】【ラピッドファイア】等が弾倉も消費するのか明記されていません。

一方、同名・近似用途の消耗装備として【フラッシュバン】【フラググレネード】も存在します。射撃技能を弾倉不要とすると、弾薬管理を迂回する恒常的な攻撃手段になり、消耗装備との役割も重なります。

### 推奨案

- 射撃技能は「射撃点1点」に加えて、射撃を伴う技能では原則として弾倉1個を消費する。
- 【ラピッドファイア】は攻撃ロールごとに弾倉1個を消費する。
- 【先制射撃】【見切り】のように追加の射撃そのものを発生させない技能は、技能使用時には弾倉を消費しない。実際に射撃攻撃を行った時点で通常どおり消費する。
- 【グレネード】技能と【フラググレネード】装備、【スタングレネード】技能と【フラッシュバン】装備は、v1.01で役割を明確に分離する。

## 4. 未定義技能【スタングレネード】

19章では基本射撃技能6種類の1つとして【スタングレネード】を列挙していますが、技能本文が存在しません。

### 推奨案

物理アイテムの【フラッシュバン】と重複しやすいため、射撃技能側の【スタングレネード】は削除し、基本射撃技能を5種類にするのではなく、別の独自技能へ置き換える。

置換候補は、弾薬管理・現代戦・分隊戦術に寄せた新技能として別途設計する。

## 5. 習得技能数の基準

18章・20章では「習得している技能の数は、常に射撃点／指揮点の半分」と記載されています。副能力値は作戦中に消費されるため、現在値を基準にすると、技能を使うたびに習得済み技能が消える解釈が成立してしまいます。

### 推奨案

習得技能数はすべて「最大値」を基準とする。

- 射撃技能数＝【射撃点の最大値】÷2（端数切捨て）
- 指揮技能数＝【指揮点の最大値】÷2（端数切捨て）

これはルール意図を変えずに曖昧さだけを除くため、承認後はP0整合修正として反映する。

## 6. P0判断後に実施する整合修正

判断確定後、以下を同じv1.01整合パッチで処理します。

- 原作からの抜粋表記・原作文をURBAN ASSAULT独自文章へ置換
- 【生命点0以下】の「行動不能／戦死」の定義統一
- 敵撤退条件の「半分未満／半分以下」統一
- 高脅威目標の撤退ルール統一
- 敵攻撃配分の端数処理統一
- `技量点／技能点／技術点` 等の用語揺れ統一
- `装備獲得表／戦利品表` の名称統一
- `退却／逃走` の名称統一
- 常備装備取得コストを軍票へ統一
- 【政治工作】の必要弾倉が0になる端数処理の修正
- 目次欠番・参照先・章番号の再点検
