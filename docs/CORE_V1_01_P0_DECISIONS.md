# URBAN ASSAULT v1.01 — P0整合性判断事項

対象：`core/core-rule-full.md`
作業ブランチ：`refactor/v1.01-core-cleanup`

この文書は、コアルール v1.01 の整合修正で確定した P0 判断と反映結果を記録するものです。

## 1. 1ラウンドの行動単位 — 承認・反映済み

- 分隊長と、戦闘に参加している各戦闘員は、原則として各ラウンドに1回ずつ行動できる。
- 攻撃を選択した場合、装備または隊員データの「射撃回数」だけ攻撃ロールを行える。
- シナリオに「攻撃人数制限」等がある場合は、そのシナリオ記載を優先する。
- 非戦闘員は通常の攻撃行動を行わない。

## 2. 弾倉消費の単位 — 承認・反映済み

- 通常の射撃攻撃は、攻撃ロール1回につき弾倉1個を消費する。
- 射撃回数2の武器・隊員が2回とも射撃する場合、原則2個消費する。
- 武器・技能に個別の消費量が明記されている場合は、その記載を優先する。
- クリティカルによる追加攻撃は、8章どおり弾倉を追加消費しない。

## 3. 射撃技能と弾倉の関係 — 承認・反映済み

- 射撃技能は「射撃点1点」に加えて、射撃を伴う技能では原則として弾倉を消費する。
- 【ラピッドファイア】は通常の攻撃ロールごとに弾倉1個を消費する。
- クリティカルによる追加攻撃では弾倉を追加消費しない。
- 【先制射撃】【見切り】のように追加の射撃そのものを発生させない技能は、技能使用時には弾倉を消費しない。
- 【グレネード】技能と【フラググレネード】装備、【スタングレネード】技能と【フラッシュバン】装備は役割を分離する。

## 4. 【スタングレネード】 — 承認・反映済み

名称は当面【スタングレネード】のままとする。

- 使用時に【射撃点】1点と弾倉1個を消費する。
- 敵1集団または高脅威目標1体を対象に【射撃ロール】を行う。
- 達成値が敵レベル以上なら、対象はそのラウンド終了まで【スタン】状態になる。
- 【スタン】状態の対象に対する分隊側の【攻撃ロール】に+1。
- 【スタン】状態の対象からの攻撃に対する分隊側の【防御ロール】に+1。
- 室内で使用する場合、この技能の【射撃ロール】に+1。
- ダメージは与えない。
- 高脅威目標の攻撃回数そのものは減少させない。

物理装備【フラッシュバン】は、使い切りの強力な制圧・突入用装備として現行の役割を維持する。

## 5. 習得技能数の基準 — 承認・反映済み

習得技能数はすべて「最大値」を基準とする。

- 射撃技能数＝【射撃点の最大値】÷2（端数切捨て）
- 指揮技能数＝【指揮点の最大値】÷2（端数切捨て）

副能力値の現在値が作戦中に低下しても、習得済み技能の種類は減少しない。

## 6. 生命点0以下 — 承認・反映済み

- 分隊長の生命点が0以下になった場合、特別な記載がない限り【戦死】とする。
- 戦死後は41章の後任分隊長・資産継承・部隊再編処理へ移行する。
- 【ファーストエイド】で戦死した分隊長や脱落した隊員を復帰させることはできない。
- 個別ルールに明示された例外がある場合は、その記載を優先する。

## 7. 敵の撤退 — 承認・反映済み

- 敵戦闘集団は、現在人数が初期人数の半分以下になった場合に撤退する。
- 高脅威目標はコアルール上の自動撤退条件を持たない。
- 高脅威目標に撤退条件を設定する場合は、シナリオ側に明記する。
- 【死ぬまで戦う】の敵は、種類を問わず撤退しない。
- シナリオに固有の撤退・戦闘終了条件がある場合は、その記載を優先する。

## 8. 【政治工作】の物資要求軽減 — 承認・反映済み

- 必要な弾倉数を10分の1にする。
- 端数は切り上げる。
- 最低1個は必要とする。

例：
- 1～10個 → 1個
- 11～20個 → 2個
- 21～30個 → 3個

## 11. 【ネゴシエーション】の高脅威目標捕虜化 — 承認・反映済み

ユーザー判断により、【ネゴシエーション】の使用条件を次のように拡張する。

- 戦闘中、敵戦闘集団が1体だけになったときに使用できる既存条件は維持する。
- 加えて、高脅威目標の生命点が1になったときにも使用できる。
- 使用時は従来どおり【指揮ロール】を行い、達成値が敵レベル以上なら対象を【捕虜】にできる。
- 【ネゴシエーション】自体は通常、捕虜確保のための拘束手段を必要としない。
- 敵戦闘集団が撤退した際の1回限りの使用条件は従来どおり維持する。
- 狂信的な敵や任務遂行のみを目的とする一部の敵への無効化、およびシナリオ記載優先も維持する。
- 【タイラップ】の「高脅威目標には使用不可」という一般規定は変更しない。個別シナリオに明示された例外は、4章のシナリオ記載優先原則に従う。

## 12. 【先制射撃】とスナイパー開始時射撃 — 承認・反映済み

ユーザー判断により、戦闘開始時の先攻処理を次のように整理する。

- 【先制射撃】は通常の先攻決定に対する明示的な割り込みとして扱う。
- 本来敵が先制する状況に加え、敵側先攻の持ち越し効果やシナリオ固有の「敵側が先攻」「敵が必ず先攻」という指定がある場合でも、【先制射撃】を使用すれば分隊側が先に行動する。
- ただし、シナリオに【先制射撃】を使用できないと明記されている場合は、その記載を優先する。
- スナイパーは屋外戦闘の第0ラウンドに、自身だけが通常の先攻順より前に1回攻撃する。
- この開始時射撃は分隊全体の先攻を変更せず、第1ラウンド以降は通常どおり確定した先攻順に従う。

これにより、【先制射撃】の戦術的な割り込み効果と、スナイパー固有の開始時1射を別処理として扱う。

## 13. 【ネゴシエーション】対象と【鹵獲】 — 承認・反映済み

ユーザー判断により、人物以外の高脅威目標に対する【ネゴシエーション】と【鹵獲】を次のように整理する。

- バリケード、無人設備、無人兵器など、人が介在しない対象は【ネゴシエーション】対象外とする。
- 人物に加え、人間の乗員・操作員が介在する車両・固定兵装は【ネゴシエーション】対象とする。
- 有人車両・有人固定兵装の生命点が1のときに【ネゴシエーション】へ成功した場合、乗員・操作員を【捕虜】にし、装備を【鹵獲】する。
- 生命点0で撃破・破壊された装備は【鹵獲】できない。
- 【鹵獲】対象は即座に戦闘から除外する。他の敵が残っている場合は戦闘を継続する。
- 車両の標準鹵獲効果は、次の固定イベントまでd66マップ決定後の一の位を±1できることとする。一の位は1～6の範囲内とし、1回のマップ決定につき1回まで使用できる。
- 車両の補正は他の強制修正・固定・振り直し等の後に適用し、補正後の結果を固定イベント出現判定にも使用する。
- 同時に有効な車両鹵獲効果は1台分のみとする。
- 固定兵装の標準鹵獲効果は、弾薬・部品の回収による弾倉+1個とする。その後、固定兵装は使用不能として扱う。
- 車両搭載兵装など1対象が車両・固定兵装の両方に該当する場合、特記がなければ車両効果のみ適用し、弾倉+1は重複しない。
- シナリオ固有の鹵獲効果がある場合は、Coreの標準効果よりシナリオ記載を優先する。

この設計により、HP1で攻撃を止めて指揮点を使うか、HP0まで撃破するかという戦術的選択を作りつつ、修理・燃料・乗員配置などの追加管理はCoreへ導入しない。

## 14. 【ネゴシエーション】の撤退処理と再試行制限 — 承認・反映済み

ユーザー判断により、【ネゴシエーション】と撤退が競合する場合の処理順、および同一対象への再試行を次のように整理する。

- 有人の高脅威目標が生命点1になった時点で撤退条件も同時に成立した場合、撤退処理の直前に【ネゴシエーション】を1回使用できる。
- 成功した場合は通常どおり【捕虜】または【鹵獲】として処理し、その対象は撤退しない。失敗した場合はそのまま撤退する。
- 【ネゴシエーション】は同一対象に対して1戦闘につき1回だけ使用できる。
- 通常の戦闘中、敵戦闘集団の撤退時、高脅威目標の撤退直前に生じる使用機会は、すべて同じ1回制限を共有する。
- 一度失敗した対象には、その戦闘中は再試行できない。
- 複数の対象が存在する場合は、各対象について1回ずつ使用できる。各使用には通常どおり指揮点1点を消費する。
- 【ネゴシエーション】対象外の敵・無人対象、およびシナリオ固有の禁止指定は従来どおり優先する。

これにより、指揮点を複数消費して同じ対象へ成功するまで連続試行する運用を防ぎ、捕虜化・鹵獲の成功判定とHP1で攻撃を止める判断に意味を持たせる。

## 15. 【死ぬまで戦う】と【ネゴシエーション】 — 承認・反映済み

ユーザー判断により、【死ぬまで戦う】と交渉不能を別概念として整理する。

- 【死ぬまで戦う】は、敵が通常の撤退を行わないことを示す反応とする。
- 【死ぬまで戦う】であること自体は、【ネゴシエーション】を禁止しない。
- 【ネゴシエーション】の通常の使用条件を満たした人物・有人高脅威目標には、反応が【死ぬまで戦う】でも使用できる。
- 成功した場合は通常どおり【捕虜】または【鹵獲】として処理し、その対象を戦闘から除外する。
- 狂信的な敵、任務遂行のみを目的とする敵など、本当に交渉不能とする対象はシナリオ側に【ネゴシエーション】無効と明記する。
- 【死ぬまで戦う】の戦闘は、全滅だけでなく、捕虜化・鹵獲またはシナリオ固有の別の戦闘終了条件が成立した場合にも終了し得る。

これにより、「撤退しない」と「交渉できない」を分離し、Coreの捕虜・鹵獲ルールを反応種別にかかわらず一貫して適用できる。

## 16. 狙撃ポイント待機要員と現場人数 — 承認・反映済み

ユーザー判断により、スナイパーおよびスポッターの「分隊には同行せず、狙撃ポイントで待機」という位置関係を人数参照効果にも一貫して適用する。

- 狙撃ポイントで待機しているスナイパーとスポッターは、「戦闘に参加している人数」「現場の人数」など、戦場に同行している人数を参照する効果では人数に含めない。
- スナイパーの屋外戦闘への攻撃参加、第0ラウンド開始時射撃、スポッターの察知振り直し、スナイパーへの攻撃補正など、各自の狙撃・観測能力は従来どおり使用できる。
- 被弾テーブルの対象外である既存規定も変更しない。
- シナリオに「狙撃ポイントの要員も人数に含める」などの明示的な例外がある場合は、シナリオ記載を優先する。

これにより、遠隔支援要員が現場人数による数的優位・防御陣地ボーナスまで発生させることを防ぎ、位置関係と人数計算を一致させる。

## 17. 第0ラウンドの複数効果の処理順 — 承認・反映済み

ユーザー判断により、第0ラウンドで使用可能な分隊側の効果が複数ある場合の処理順を次のように整理する。

- スナイパーの開始時射撃、消耗装備、一部スキルなど、第0ラウンドで使用可能な分隊側の効果はプレイヤーが任意の順番で処理できる。
- 1つの効果を最後まで処理してから次の効果へ進む。
- 先の効果によって敵人数・生命点・状態などが変化した場合、後続の効果は変化後の戦闘状況を参照する。
- シナリオ、装備、技能などに明示的な処理順が記載されている場合は、その個別記載を優先する。
- 第0ラウンドで直接ダメージを与える技能を使用できない既存制限など、各効果固有の使用条件は変更しない。

これにより、第0ラウンドに複数の選択肢が重なった場合でも固定順を追加せず、プレイヤーが状況に応じて投入順を判断できる。

## 18. 第0ラウンドの消耗装備使用上限 — 承認・反映済み

ユーザー判断により、第0ラウンドにおける消耗装備の使用数を次のように整理する。

- 分隊長が第0ラウンド中に使用できる消耗装備は、特記がない限り1個までとする。
- 第0ラウンドで消耗装備を使用しても、第1ラウンドの分隊長の行動は消費しない。
- スナイパーの開始時射撃、【先制射撃】など行動に数えない技能・効果とは併用できる。
- 複数の第0ラウンド効果を併用する場合は、承認済みの任意処理順ルールに従う。
- シナリオや個別の装備に第0ラウンドでの使用数が明記されている場合は、その個別記載を優先する。

これにより、第0ラウンドを交戦開始時の戦術準備として維持しつつ、所持している消耗装備を通常ラウンドの行動制約なしに連続投入できる解釈を防ぐ。

## 19. 【フラッシュバン】の効果発動時点 — 承認・反映済み

ユーザー判断により、【フラッシュバン】の戦闘時効果を「使用したラウンド」基準から「対象の次の攻撃」基準へ変更する。

- 【フラッシュバン】の使用に成功した場合、対象が次に攻撃を行う時に効果を適用する。
- 敵戦闘集団を対象とした場合、その次の攻撃を無効化する。
- 高脅威目標を対象とした場合、その次の攻撃時の攻撃回数を-1する。
- 分隊側が先攻して使用した場合は、同一ラウンド中に行われる敵の攻撃が「次の攻撃」であれば直ちに効果を適用する。
- 敵側が先攻し、その敵側行動後に使用した場合は、対象が次に攻撃する機会まで効果を保持する。
- 第0ラウンドに使用した場合も同じ原則に従い、対象の最初の攻撃機会に効果を適用する。
- 効果は使用した戦闘中だけ継続し、マップを越えて持ち越さない。対象が次に攻撃する前に戦闘が終了した場合、未発動のまま効果を終了する。

これにより、先攻・後攻によって【フラッシュバン】の有効性が失われる問題を解消しつつ、次の遭遇へ妨害効果を保存する運用は認めない。


## 20. 戦闘終了要約と詳細規定の同期 — 整合修正済み

既に確定していた戦闘終了規定と、36章末尾の要約記述に不足があったため、判断不要の文章整合として同期した。

- 【ネゴシエーション】による【捕虜】化・【鹵獲】などで、戦闘対象となる敵がいなくなった場合も戦闘終了となることを要約へ反映した。
- 複数の敵が残っている場合、1体または1対象を【捕虜】・【鹵獲】しただけでは戦闘全体は終了しない既存規定を明記した。
- シナリオ固有の戦闘終了条件が成立した場合は、その記載を優先する既存規定を要約へ反映した。
- 新しい終了条件・制限・能力は追加しておらず、ゲームバランスへの変更はない。

この修正は、既存の詳細規定と要約の意味を一致させるための同期である。

## 21. 分隊長戦死時の弾倉継承と軍票化 — 承認・反映済み

ユーザー判断により、41章の部隊再編時における残弾倉の扱いを次のように明確化する。

- 分隊長戦死時、作戦終了時点で残っている弾倉資源は後任分隊長へ全数引き継ぐ。
- 引き継ぎを確認した後、通常の作戦終了時処理に従って残弾倉をすべて軍票へ変換する。
- 得られた軍票は、再編後の分隊装備を充足させるために使用できる。
- この処理はゲームに不慣れなプレイヤーへの救済処置として意図した仕様である。
- 分隊長戦死や失敗を意図的に利用して軍票を得るプレイも禁止しない。ソロTRPGとして、プレイヤーがその遊び方を楽しむ場合は追加制限を設けない。
- 標準バランステストでは、このような意図的な資源獲得プレイは想定外として考慮しない。

この決定は41章の「弾倉資源を引き継ぐ」と、44章等の通常の作戦終了時弾薬整理を競合させず、処理順を明確にするものである。

## 22. MREの支給単位 — 承認・反映済み

ユーザー判断により、MREの支給単位をシナリオ単位から作戦単位へ整理する。

- 特記がない場合、各作戦開始時にMREを2食分所持する。
- MREは購入コスト不要。
- 未使用分は作戦終了時に失われ、次の作戦へ持ち越さない。
- 複数作戦からなるシナリオや、同じ作戦への再挑戦でも、各作戦開始時に2食支給する。

これにより、長期シナリオでも各作戦を同一の初期条件で開始でき、31章の「次の作戦へ持ち越さない」と支給タイミングを一致させた。

## 23. 2人プレイ時のシナリオ数値・支給資源 — 承認・反映済み

ユーザー判断により、2人プレイ時の基本則を次のように確定した。

- シナリオが作戦全体へ指定する数値・支給資源は、特記がない限り2人で共有する。
- 初期弾倉、作戦単位の支給消耗品、戦闘参加人数上限などは人数分に倍増しない。
- 各分隊長固有の能力値、技能、個人装備、Core規定で各分隊長へ付与されるMREなどは個別に管理する。
- シナリオ側に個別支給の明記がある場合は、その記載を優先する。

Core 45「2人の分隊長」へこの原則を追記した。
