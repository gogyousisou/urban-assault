# URBAN ASSAULT v1.01 — P0整合性判断事項

対象：`core/core-rule-full.md`
作業ブランチ：`refactor/v1.01-core-cleanup`

この文書は、コアルールv1.01の整合修正にあたり、既存ルールから一意に決められないP0事項の判断記録です。

## 1. 1ラウンドの行動単位 — 承認済み

- 分隊長と、戦闘に参加している各戦闘員は、原則として各ラウンドに1回ずつ行動できる。
- 攻撃を選択した場合、装備または隊員データの「射撃回数」だけ攻撃ロールを行える。
- シナリオに「攻撃人数制限」等がある場合は、そのシナリオ記載を優先する。
- 非戦闘員は通常の攻撃行動を行わない。

## 2. 弾倉消費の単位 — 承認済み

- 通常の射撃攻撃は、攻撃ロール1回につき弾倉1個を消費する。
- 射撃回数2の武器・隊員が2回とも射撃する場合、原則2個消費する。
- 武器・技能に個別の消費量が明記されている場合は、その記載を優先する。
- クリティカルによる追加攻撃は、8章どおり弾倉を追加消費しない。

## 3. 射撃技能と弾倉の関係 — 承認済み

- 射撃技能は「射撃点1点」に加えて、射撃を伴う技能では原則として弾倉1個を消費する。
- 【ラピッドファイア】は攻撃ロールごとに弾倉1個を消費する。
- 【先制射撃】【見切り】のように追加の射撃そのものを発生させない技能は、技能使用時には弾倉を消費しない。実際に射撃攻撃を行った時点で通常どおり消費する。
- 【グレネード】技能と【フラググレネード】装備、【スタングレネード】技能と【フラッシュバン】装備は役割を分離する。

## 4. 【スタングレネード】 — 承認済み

名称は当面【スタングレネード】のままとする。

技能効果は次のとおりとする。

- 使用時に【射撃点】1点と弾倉1個を消費する。
- 敵1集団または高脅威目標1体を対象に【射撃ロール】を行う。
- 達成値が敵レベル以上なら、対象はそのラウンド終了まで【スタン】状態になる。
- 【スタン】状態の対象に対する分隊側の【攻撃ロール】に+1の修正を与える。
- 【スタン】状態の対象からの攻撃に対する分隊側の【防御ロール】に+1の修正を与える。
- 室内で使用する場合、スタングレネード使用時の【射撃ロール】に+1の修正を与える。
- ダメージは与えない。
- 高脅威目標の攻撃回数そのものは減少させない。

物理装備【フラッシュバン】は、使い切りの強力な制圧・突入用装備として現行の役割を維持する。

## 5. 習得技能数の基準 — P0明確化

習得技能数はすべて「最大値」を基準とする。

- 射撃技能数＝【射撃点の最大値】÷2（端数切捨て）
- 指揮技能数＝【指揮点の最大値】÷2（端数切捨て）

副能力値の現在値が作戦中に低下しても、習得済み技能の種類は減少しない。

## 6. P0判断後に実施する整合修正

判断確定後、以下をv1.01整合パッチで処理します。

- 敵撤退条件の「半分未満／半分以下」統一
- 高脅威目標の撤退ルール統一

- `技量点／技能点／技術点` 等の用語揺れ統一

- `退却／逃走` の名称統一
