# URBAN ASSAULT v1.01 — P0整合性判断事項

対象：`core/core-rule-full.md`
作業ブランチ：`refactor/v1.01-core-cleanup`

この文書は、コアルール v1.01 の整合修正にあたり、既存ルールから一意に決められない P0 事項の判断記録です。

## 1. 1ラウンドの行動単位 — 承認・反映済み

- 分隊長と、戦闘に参加している各戦闘員は、原則として各ラウンドに1回ずつ行動できる。
- 攻撃を選択した場合、装備または隊員データの「射撃回数」だけ攻撃ロールを行える。
- シナリオに「攻撃人数制限」等がある場合は、そのシナリオ記載を優先する。
- 非戦闘員は通常の攻撃行動を行わない。

## 2. 弾倉消費の単位 — 承認・反映済み

- 通常の射撃攻撃は、攻撃ロール1回につき弾倉1個を消費する。
- 射撃回数2の武器・隊員が2回とも射撃する場合、原則2個消費する。
- 武器・技能に個別の消費量が明記されている場合は、その記載を優先する。
- クリティカルによる追加攻撃は、8章どおり弾倉を追加消費しない。

## 3. 射撃技能と弾倉の関係 — 承認・反映済み

- 射撃技能は「射撃点1点」に加えて、射撃を伴う技能では原則として弾倉1個を消費する。
- 【ラピッドファイア】は通常の攻撃ロールごとに弾倉1個を消費する。
- クリティカルによる追加攻撃では弾倉を追加消費しない。
- 【先制射撃】【見切り】のように追加の射撃そのものを発生させない技能は、技能使用時には弾倉を消費しない。
- 【グレネード】技能と【フラググレネード】装備、【スタングレネード】技能と【フラッシュバン】装備は役割を分離する。

## 4. 【スタングレネード】 — 承認・反映済み

名称は当面【スタングレネード】のままとする。

- 使用時に【射撃点】1点と弾倉1個を消費する。
- 敵1集団または高脅威目標1体を対象に【射撃ロール】を行う。
- 達成値が敵レベル以上なら、対象はそのラウンド終了まで【スタン】状態になる。
- 【スタン】状態の対象に対する分隊側の【攻撃ロール】に+1。
- 【スタン】状態の対象からの攻撃に対する分隊側の【防御ロール】に+1。
- 室内で使用する場合、この技能の【射撃ロール】に+1。
- ダメージは与えない。
- 高脅威目標の攻撃回数そのものは減少させない。

物理装備【フラッシュバン】は、使い切りの強力な制圧・突入用装備として現行の役割を維持する。

## 5. 習得技能数の基準 — 反映済み

習得技能数はすべて「最大値」を基準とする。

- 射撃技能数＝【射撃点の最大値】÷2（端数切捨て）
- 指揮技能数＝【指揮点の最大値】÷2（端数切捨て）

副能力値の現在値が作戦中に低下しても、習得済み技能の種類は減少しない。

## 6. 判断不要として反映済みの整合修正

以下はゲーム性を新たに決めるものではなく、既存意図の明確化・誤記修正として反映済み。

- 原作からの抜粋表記・原作文を URBAN ASSAULT 独自文章へ置換。
- 作品情報を v1.01 の承認済み表記へ更新。
- 目次を 01～47 章まで補完。
- 敵攻撃回数が奇数の場合の割り当てを、総攻撃回数を超えない処理へ修正。
- 分隊員の防御に使う「技能点」を「技量点」へ修正。
- `装備獲得表／装備獲得処理` を `戦利品表／戦利品処理` へ整理。
- 敵側の `逃走` を `撤退`、分隊側を `退却` に整理。
- 「冒険記録紙」を「分隊記録紙」へ修正。
- 再編段階を「恒久的成長」とする矛盾表記を削除し、同一シナリオ内の救済値として明確化。
- 常備装備・消耗装備の取得コストは現行本文で軍票に統一済みであることを確認。

## 7. 次にユーザー判断が必要な3項目

### 7-1. 分隊長の生命点が0以下になった場合

現行13章では「行動不能」、41章では「戦死」となっており、両立していない。

**推奨案：生命点0以下＝戦死**

理由：41章には後任分隊長、資産継承、再編段階まで含む死亡後処理がすでに設計されている一方、生命点0から復帰するための「行動不能」専用ルールは存在しないため。

採用時は13章を「戦死」に統一し、【ファーストエイド】等の「行動不能」は別の状態異常にのみ使う。

### 7-2. 敵の撤退条件

現行35章では「初期値の半分未満」、38章では「初期値の半分以下」。さらに高脅威目標について、35章は「撤退条件を持たないことが多い」、38章は一度「半分以下で撤退」とした後に「原則死ぬまで戦う」としている。

**推奨案：**

- 敵戦闘集団：初期人数の半分以下で撤退。
- 高脅威目標：コアルールでは自動撤退しない。
- 高脅威目標に撤退条件を設ける場合は、シナリオ側に明記する。
- 【死ぬまで戦う】の敵は、種類を問わず撤退しない。

これにより「通常敵は50%損耗で撤退、高脅威目標はシナリオ依存」という役割分担になる。

### 7-3. 【政治工作】の弾倉要求軽減

現行は「必要弾倉数を10分の1、端数切捨て」となっており、元の要求が1～9個なら0個になる。

**推奨案：必要弾倉数を10分の1、端数切り上げ、最低1個。**

例：
- 1～10個 → 1個
- 11～20個 → 2個
- 21～30個 → 3個

政治工作を強力な軽減技能として維持しつつ、物資要求そのものを完全無料にはしない。
