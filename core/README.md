# URBAN ASSAULT Core Rules

このディレクトリは、URBAN ASSAULT のコアルールを管理します。

## 正本

- `core-rule-full.md` — コアルールの開発正本

ルール本文の修正は `core-rule-full.md` に対して行います。
`README.md` は案内用であり、ルール本文には含めません。

## 公開運用

- `main`：開発正本。公開リポジトリのため、常に一般公開可能な内容だけを格納します。
- `public-release`：確認済みの公開安定版を格納します。

公開フローは `main → 内容確認 → public-release` とします。

## ローグライクハーフとの関係

URBAN ASSAULT は、FT書房『ローグライクハーフ』の利用規則に基づいて制作する非公式バリアントルールです。
公式作品は設計研究の参考とし、URBAN ASSAULT の本文・シナリオ・データは独自文章・独自データを原則とします。

- ローグライクハーフ基本ルール：<https://ftbooks.booth.pm/items/4671946>
- 制作に関する利用規則：<https://ftbooks.xyz/ftnews/gamebook/RogueLikeHalf_TOS.pdf>

公式作品の本文や、再配布を許可されていない第三者著作物はこのリポジトリに格納しません。
